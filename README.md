## Selected work

### [Pithos](https://elpis.technology/products/pithos/)
On-premises retrieval layer for enterprise AI. Semantic, Turkish lexical and exact-identifier search paths are filtered by NTFS, Active Directory and SharePoint permissions before results merge. Evaluated at **0.8929 NDCG@10** and **1.00 Recall@20** on 530 documents and 60 Turkish queries.

### Hermes
Local vision-language pipeline for Turkish e-invoice and e-archive processing. Uses Qwen3-VL-8B with MLX-LM, validation and SAP BAPI/IDoc integration for automated posting.

### [WebWeaver](https://github.com/usanli/WebWeaver)
Multi-agent LLM pipeline that generates websites and applications through specialized agents for planning, design, content, implementation and QA. MSc capstone, ranked first among all capstone projects.

### Petrol Ofisi AI Partnership
Enterprise AI work spanning executive training, a local-LLM Business Transformation Cockpit and process automation. The cockpit combines deterministic workload analysis with local LLM generation and human workshop validation.

### Enterprise RAG Knowledge Assistant
LangGraph + pgvector retrieval assistant, containerized and deployed on GCP for enterprise knowledge access.
